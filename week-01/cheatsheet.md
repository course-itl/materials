# Шпаргалка команд курса — неделя 1

Одна страница. Не запоминать — держать под рукой; через две недели она вам не понадобится.

## Ориентация

```
pwd                     где я
ls -la                  список файлов, включая скрытые, с правами
cd путь                 перейти (cd — домой, cd - — назад, .. — вверх)
tree -L 2               дерево на 2 уровня (если установлен)
file имя                что это за файл
du -sh каталог          сколько весит
```

## Чтение файлов

```
cat файл                весь файл
less файл               постранично (q — выход, / — поиск, G — в конец)
head -20 файл           первые 20 строк;  head -c 100 — первые 100 байт
tail -20 файл           последние;  tail -f — следить за растущим логом
wc -l файл              число строк (-w слова, -c байты)
```

## Поиск

```
find каталог -name '*.py'         по имени (шаблон в кавычках!)
find каталог -size 1337c          по размеру ровно в байтах
find каталог -mmin -10            изменён за последние 10 минут
find каталог -type d              только каталоги
grep -r 'строка' каталог          искать строку рекурсивно
grep -n 'строка' файл             с номерами строк
grep -c 'строка' файл             только посчитать
grep -v 'строка'                  инвертировать (всё, где НЕТ строки)
grep -E 'рег|улярка'              расширенные regex
```

## Права

```
ls -l                   -rwxr-xr-- владелец/группа/остальные
chmod +x скрипт         сделать исполняемым
chmod +r файл           вернуть право чтения
chown юзер файл         сменить владельца (обычно нужен sudo)
```

## Архивы

```
tar -tf архив.tar               посмотреть содержимое БЕЗ распаковки
tar -xf архив.tar               распаковать (-C каталог — «куда»)
tar -czf арх.tar.gz каталог     запаковать с gzip
```

## Пайпы и редиректы

```
cmd1 | cmd2             stdout первой → stdin второй
cmd > файл              stdout в файл (перезапись);  >> — дописать
cmd 2> файл             stderr в файл;  2>&1 — stderr туда же, куда stdout
cmd < файл              файл → stdin
cmd1 && cmd2            вторая — только если первая успешна
echo $?                 exit-код последней команды (0 = успех)
```

Классический конвейер частотного анализа — выучите как идиому:

```
... | sort | uniq -c | sort -rn | head -10
```

## Резка и склейка текста

```
cut -d' ' -f1           первое поле, разделитель — пробел
sort                    сортировка (-n числа, -r обратно, -u уникальные)
uniq -c                 схлопнуть подряд идущие дубли, посчитать
tr 'A-Z' 'a-z'          замена символов;  tr -d '\r' — удалить
awk '{print $2}'        второе поле (разделитель — любые пробелы)
awk '{s+=$1} END{print s}'   сумма первого поля
sed 's/было/стало/g'    замена по regex
```

## Процессы

```
ps aux                  все процессы;  ps aux | grep имя — найти
htop                    интерактивный монитор (F9 — послать сигнал, q — выход)
kill PID                послать SIGTERM («завершись, пожалуйста»)
kill -9 PID             SIGKILL («умри») — только если TERM не помог
cmd &                   запустить в фоне
jobs / fg / bg          фоновые задачи текущего шелла
Ctrl+C                  SIGINT текущему процессу
Ctrl+Z                  приостановить (потом bg или fg)
```

## Удалённый сервер

```
ssh course                       зайти (после настройки ~/.ssh/config)
scp файл course:путь             скопировать туда
scp course:путь файл             скопировать оттуда
tmux                             новая сессия (внутри: Ctrl+b d — отцепиться)
tmux attach                      вернуться в сессию (переживает обрыв связи!)
```

## Помощь

```
man команда             полная документация (/ — поиск внутри, q — выход)
команда --help          краткая справка
tldr команда            примеры типичного использования (если установлен)
type команда            что это: бинарник, алиас, встроенная
```
