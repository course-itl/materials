# Python для плюсовиков

Это шпаргалка для тех, кто свободно пишет на C++ и хочет за час начать писать на Python скрипты в двадцать-пятьдесят строк: генераторы, чекеры, обработку файлов. Она не учебник языка, а перевод с языка, который вы знаете, на язык, который вам нужен, поэтому почти каждый раздел построен как таблица соответствий или как пример «в C++ так, в Python вот так». Прочитайте её один раз подряд, чтобы знать, что в ней есть, а дальше пользуйтесь как справочником по заголовкам.

Здесь только «как». За «почему» отвечает гл. 4 учебника «Python: как он думает»: почему присваивание не копирует список, почему значение по умолчанию у аргумента запоминается между вызовами, почему ошибка в типе обнаруживается только при выполнении и откуда берётся медленность. Разделы, чью модель объясняет глава, помечены «(гл. 4)»; если какая-то строка шпаргалки кажется странной, а не просто незнакомой, это сигнал открыть главу, а не заучить строку. Инженерная сторона Python, от проектов и пакетов до тестов и типизации, будет во второй четверти.

## Зачем второй язык, если есть C++ и bash

Коротко, потому что подробно об этом гл. 4. Bash это клей между программами, C++ это вычисления на скорость, а между ними остаётся дыра: скрипт, который обрабатывает данные, но не обязан быть быстрым. Генератор тестов, чекер, разбор лога, переименование файлов по правилу писать на C++ долго (компиляция, ручной ввод-вывод, нет словарей для строк из коробки), а на bash больно (нет структур данных, нет дробей). Python закрывает эту дыру: программа выходит в несколько раз короче, чем на C++, и при этом остаётся настоящим языком со словарями, строками, файлами и библиотекой почти на всё. Цена одна, скорость: в десятки и сотни раз медленнее C++. Для олимпиадного решения это приговор, для скрипта неважно.

## Запуск (гл. 4)

```bash
python3 script.py arg1 arg2        # интерпретатор читает файл и выполняет сверху вниз
python3 -c 'print(2**100)'         # однострочник
python3                            # интерактивный режим (REPL) — калькулятор и песочница; выход: exit() или Ctrl+D
```

Отдельного шага компиляции нет: интерпретатор читает файл и выполняет его сверху вниз. Ошибки в синтаксисе он находит до выполнения первой строки, а ошибки в типах только тогда, когда дойдёт до соответствующей строки, поэтому запускать скрипт на маленьком вводе стоит как можно раньше. Первая строка `#!/usr/bin/env python3` и `chmod +x` на файл делают его программой, которую можно запускать как `./script.py` (гл. 1 учебника).

## Синтаксис: главное отличие

Блоки выделяются **отступами**, а не фигурными скобками. Двоеточие открывает блок, отступ (4 пробела) — его тело, конец отступа — конец блока. Точки с запятой нет, круглые скобки вокруг условий не нужны.

```python
# C++                                  # Python
if (a > b) {                           if a > b:
    x = a;                                 x = a
} else if (a == b) {                   elif a == b:
    x = 0;                                 x = 0
} else {                               else:
    x = b;                                 x = b
}
```

Комментарий — `#`. Логика — словами: `and`, `or`, `not`. Нет `++` и `--`: пишите `i += 1`. Нет `? :` — есть `x = a if a > b else b`.

## Переменные и типы (гл. 4)

Типы есть, но принадлежат они **значениям**, а не переменным: переменная это просто имя, привязанное к объекту, и после `x = 5` можно написать `x = "пять"`, перевесив имя на другой объект. Объявлений нет, первое присваивание создаёт переменную.

| C++ | Python | Заметки |
|---|---|---|
| `int`, `long long` | `int` | **без переполнения**: `2**100` — просто большое число |
| `double` | `float` | это double; `1/2 == 0.5` — деление всегда дробное |
| `a / b` для int | `a // b` | целочисленное деление, **округляет вниз**: `-7 // 2 == -4` (в C++ было бы −3) |
| `a % b` | `a % b` | знак результата — как у делителя: `-7 % 2 == 1` |
| `pow(a, b)` | `a ** b` | |
| `bool` | `bool` | `True`, `False` — с заглавной |
| `nullptr` | `None` | «ничего»; проверка: `if x is None:` |
| `std::string` | `str` | неизменяемая; символ — тоже `str` длины 1 |
| `char` | — | нет отдельного типа; `ord('a') == 97`, `chr(97) == 'a'` |

Преобразования — функциями: `int("42")`, `str(42)`, `float("3.5")`, `int(3.9) == 3`.

**Истинность**: в условии любое значение приводится к bool: `0`, `0.0`, `""`, `[]`, `{}`, `None` — ложь; всё остальное — истина. `if lst:` — «если список непуст».

## Строки

```python
s = "hello"
len(s)                  # 5
s[0], s[-1]             # 'h', 'o' — отрицательный индекс считает с конца
s[1:3]                  # 'el' — срез [от, до): как полуинтервал в C++
s.upper(), s.lower(), s.strip()          # регистр; strip — убрать пробелы по краям
s.split()               # ['hello'] — по любым пробелам; s.split(",") — по запятой
",".join(["a", "b"])    # 'a,b' — обратно к split
s.startswith("he"), "ell" in s           # проверки
s.replace("l", "L")     # новая строка; исходная неизменяема
f"n = {n}, ответ = {ans:.2f}"            # f-строка: подстановка и форматирование ({x:5d}, {x:.3f}, {x:>10})
```

Строки неизменяемы: `s[0] = 'H'` — ошибка; собирайте новую. Конкатенация в цикле — медленно; собирайте список и делайте `"".join(...)`.

## Контейнеры (гл. 4)

| C++ | Python | |
|---|---|---|
| `vector<T>` | `list` | `a = [1, 2, 3]`; `a.append(4)`; `a[i]`; `len(a)`; `a.sort()`; `a.pop()` |
| `pair`, `tuple` | `tuple` | `p = (1, 2)`; неизменяемый; распаковка: `x, y = p` |
| `unordered_map<K,V>` | `dict` | `d = {}`; `d["key"] = 1`; `d.get("k", 0)`; `for k, v in d.items()` |
| `unordered_set<T>` | `set` | `s = set()`; `s.add(x)`; `x in s`; `len(s)` |
| `map<K,V>` (упорядоченный) | — | `sorted(d)` — когда нужен порядок |
| `deque` | `collections.deque` | `popleft()` за O(1) |
| `priority_queue` | `heapq` | функции над списком |

Список — не массив фиксированного типа: в нём может лежать что угодно, включая другие списки. `a = [[0] * m for _ in range(n)]` — матрица $n \times m$ (не `[[0]*m]*n` — получится $n$ ссылок на одну строку).

**Ловушка №1 для плюсовика:** присваивание не копирует. После `b = a` имя `b` становится вторым именем того же списка, и `b.append(1)` изменит то, что видно через `a`. Копию нужно делать явно: `b = a.copy()` или `b = list(a)`. То же относится к словарям и множествам. С числами и строками этой проблемы нет, потому что их нельзя изменить на месте (почему так устроено, объясняет гл. 4, раздел «Всё — объект, а имя — ярлык»).

Срезы работают на списках: `a[1:3]`, `a[::-1]` (перевернуть), `a[:k]` (первые k).

```python
from collections import Counter, defaultdict
cnt = Counter(words)               # словарь слово → сколько раз; cnt.most_common(10)
d = defaultdict(list)              # d[k] сам создаст пустой список при первом обращении
```

## Циклы

```python
for x in a:                        # по элементам — как for (auto x : a)
for i in range(n):                 # 0, 1, ..., n-1 — правая граница НЕ включается
for i in range(1, n + 1):          # 1..n
for i in range(n - 1, -1, -1):     # n-1 .. 0
for i, x in enumerate(a):          # индекс и элемент
for x, y in zip(a, b):             # параллельно по двум
while cond:
    ...
```

`break`, `continue` — как в C++. Классического `for (i = 0; i < n; i++)` нет — только `range`.

**Списковые включения** — то, что делает Python коротким:

```python
squares = [x * x for x in range(10)]
evens = [x for x in a if x % 2 == 0]
nums = [int(t) for t in line.split()]           # разобрать строку чисел — идиома №1
total = sum(x * x for x in a)                   # без скобок — «ленивый» генератор, без списка в памяти
```

Полезные встроенные функции: `sum`, `min`, `max`, `len`, `sorted`, `reversed`, `abs`, `any`, `all`.

## Функции (гл. 4)

```python
def solve(a, k=1):                 # аргументы без типов; k — со значением по умолчанию
    """Что делает функция."""       # докстринг — комментарий-документация
    best = 0
    for x in a:
        best = max(best, x * k)
    return best                    # можно вернуть несколько: return l, r  → l, r = solve(a)

def f(x: int) -> int:              # аннотации типов — необязательны, ничего не проверяют, но читаются
    return x + 1
```

Аргументы передаются как ссылки на объекты, без копирования: список, переданный в функцию, можно изменить изнутри, и это будет видно снаружи, а число изменить нельзя, потому что число неизменяемо. **Ловушка №2:** значение по умолчанию вычисляется один раз, в момент определения функции, поэтому `def f(a=[])` даёт один общий список на все вызовы. Пишите `def f(a=None): if a is None: a = []`; откуда берётся это поведение, в гл. 4.

Лямбда — только выражение: `key=lambda p: (p[1], p[0])`. Функции — обычные значения: их можно передавать и хранить.

## Сортировка

```python
a.sort()                                   # на месте
b = sorted(a)                              # новая копия
a.sort(reverse=True)
pairs.sort(key=lambda p: (-p[1], p[0]))    # по убыванию второго, при равенстве — по возрастанию первого
```

Ключ — функция, вычисляющая, *по чему* сравнивать; кортежи сравниваются лексикографически — отсюда идиома с `(-count, word)`. Сортировка стабильная. Никаких компараторов «меньше» писать не надо.

## Ввод и вывод

import sys

data = sys.stdin.read().split()            # весь stdin → список слов. Быстро и просто

## Файлы

```python
with open("input.txt") as f:               # with закроет файл сам, даже при ошибке
    text = f.read()                        # всё содержимое строкой
    # или: lines = f.readlines(); или: for line in f:

with open("out.txt", "w") as f:            # "w" — перезаписать; "a" — дописать
    f.write("hello\n")                     # write не добавляет \n сам
    print("x =", 1, file=f)                # print умеет в файл

with open("data.bin", "rb") as f:          # бинарный режим: читаем bytes, а не str
    raw = f.read()
```

Текст (`str`) и байты (`bytes`) — разные типы. Файл в текстовом режиме декодируется (UTF-8 по умолчанию), в бинарном — нет. Хеши (`hashlib`) и сжатие (`zlib`) работают с байтами: `"строка".encode()` → bytes, `b.decode()` → str. Это понадобится на неделе 4 в mygit.

```python
from pathlib import Path
p = Path("src") / "main.py"                # склейка путей через /
p.exists(), p.is_file(), p.is_dir()
p.name, p.suffix, p.parent                 # 'main.py', '.py', Path('src')
p.read_text(), p.write_text("...")         # быстрый вариант open/read/close
p.stat().st_size                           # размер в байтах
for q in Path(".").rglob("*.py"):          # рекурсивный обход по шаблону (включая скрытые каталоги)
    print(q, q.relative_to("."))
p.mkdir(parents=True, exist_ok=True)       # mkdir -p
```

`pathlib` — современный способ работать с путями; старый `os.path` встретите в чужом коде.

## Ошибки (гл. 4)

```python
try:
    with open(name) as f:
        data = f.read()
except FileNotFoundError:
    print(f"нет файла: {name}", file=sys.stderr)
    sys.exit(1)
except (ValueError, OSError) as e:         # несколько типов; e — объект ошибки, str(e) — сообщение
    ...
```

Ошибка в Python это **исключение**. Если его никто не поймал, интерпретатор печатает трассировку (traceback) в stderr и завершает программу с кодом 1. Трассировку читают **снизу вверх**: последняя строка говорит, что случилось, строки над ней, где именно. Для скрипта в тридцать строк часто разумно ничего не ловить и дать ему упасть с трассировкой, она информативнее любого вашего сообщения. Ловить стоит только то, на что вы хотите отреагировать иначе, чем падением: например, файл не найден, значит сообщение в stderr, остальные файлы обработать, в конце код 1. Подробнее о модели исключений и о том, когда `except` вреден, в гл. 4.

## Скелет скрипта (гл. 4)

```python
#!/usr/bin/env python3
"""script.py — что делает. Использование: script.py ARG"""
import sys


def main() -> int:
    ...
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

Последние две строки означают, что код внутри выполнится, только если файл запущен как программа, а не импортирован как модуль (что такое `__name__` и почему файл «выполняется» при импорте, объясняет гл. 4). Для двадцатистрочного скрипта можно писать и «плоско», без `main`, но привычка окупится во второй четверти.

## Ловушки для плюсовика — сводка (гл. 4)

Почти все пункты ниже это следствия одной модели «имя это ярлык на объекте» и одного факта «файл выполняется сверху вниз». Если список кажется набором случайных капризов, прочитайте гл. 4: после неё он превращается в три правила.

1. `b = a` для списка/словаря — второе имя, не копия.
2. `range(n)` не включает `n`; `randint(a, b)` включает `b`.
3. `//` округляет вниз, `%` берёт знак делителя: `-7 // 2 == -4`, `-7 % 2 == 1`.
4. `/` всегда дробное, даже для целых.
5. Отступы — синтаксис; смесь табов и пробелов — ошибка.
6. Значение по умолчанию у аргумента вычисляется один раз.
7. `==` сравнивает значения, `is` — тождество объектов; с `None` — только `is`.
8. Строки неизменяемы; конкатенация в цикле — квадратична.
9. Рекурсия ограничена глубиной ~1000 (`sys.setrecursionlimit`), и она медленная — глубокий DFS пишите итеративно или не на Python.
10. Скорость: ~$10^7$ простых операций в секунду, не $10^9$. Для скрипта — неважно; для олимпиады — C++.
