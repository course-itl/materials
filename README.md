# Материалы курса информатики

Годовой курс: инструменты разработки, устройство систем «под капотом», сети, базы данных, большие системы — всё на глубине «сделай сам».

## Недели

- [Неделя 2 — Bash-скрипты: стресс-тестировщик](week-02/README.md)

## Как устроена сдача

У каждого ученика в организации свой репозиторий `hw-<фамилия>` — портфолио за год. Задания сдаются туда: сначала обычными коммитами, с недели 3 — через pull request с ревью. В каждой неделе есть **core** (обязательный минимум) и **bonus** (расширения к «отлично»).
